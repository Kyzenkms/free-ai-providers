### 💡 Usage Tips
* **Don't burn all sites at once:** Starter credits expire quickly. Use one service at a time, test it, and move to the next when your credits run out.
* **Always verify accounts:** Most platforms require GitHub or Telegram verification before granting full credit balances.
* **Keep keys safe:** Never commit raw API keys to public repositories.
* **Test live first:** Use our **[Live API Checker](https://ai.solisk.org/checker)** to check latency and verify models before plugging them into your IDE.
